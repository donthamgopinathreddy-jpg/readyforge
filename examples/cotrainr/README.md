# Cotrainr reference profile

Cotrainr is the first real-world reference used to shape ReadyForge's audit methodology.

This example intentionally contains no production credentials, customer data or proprietary application source.

Project-specific rules should remain in the private application repository and extend ReadyForge's generic controls.

Examples of product-specific checks:

- provider verification is server-authoritative
- connection allowance is transactional
- messaging entitlement is server-authoritative
- video-meeting creation cannot bypass server validation
- fitness data cannot be fabricated when unavailable
- partner member passes must be unique and appropriately protected for their threat model
